# sgpla-web

Carpeta reservada para el frontend de SGPLa (React).

Todavía no contiene código. Cuando se cree el esqueleto se agregará `.github/workflows/frontend-ci.yml`, filtrado a cambios en `sgpla-web/**`.

La API REST se encuentra en `../sgpla-backend`. Su configuración de CORS (`Cors:OrigenesPermitidos`) debe incluir el origen del servidor de desarrollo del frontend.
